# 公式功能实现计划

## Context

当前项目对公式的支持处于"基础语法识别"阶段：解析器能识别 `$...$`（行内公式）和 `$$...$$`（块级公式），但渲染和编辑体验不完整。

- **行内公式**：有样式（math_fg/math_bg/等宽/斜体），但缺少快捷键和工具栏入口
- **块级公式**：用 `ft.Markdown` 渲染 LaTeX，但作为围栏块**不可编辑**（无法修改公式内容）
- **Flet 能力**：`ft.Markdown` 有 `latex_scale_factor`/`latex_style` 参数，支持 LaTeX 渲染

目标：参考 Typora 效果，实现行内公式折叠 `$` 标记 + 块级公式点击编辑 + 快捷键/工具栏入口。

## 实现方案

### 1. 行内公式（$...$）— 快捷键 + 工具栏入口

行内公式的 `display_text`（segment_helpers.py:87）已返回 `seg.text`（不含 `$`），`split_seg_for_display`（line 114-117）已有拆分逻辑 `[$, content, $]`，`segment_style`（styles.py:182-188）已有 math 样式。**主要缺失的是快捷键和工具栏入口**。

**改动：**

- `utils/segment_helpers.py:35-43` — `WRAP_SYNTAX` 新增 `SegType.INLINE_MATH: ("$", "$")`
- `views/editor.py` `apply_inline_format`（~line 967）— seg_type 字典新增 `"inline_math": SegType.INLINE_MATH`
- `views/editor.py` `_apply_outward_wrap`（~line 1007）— 同步新增映射
- `services/shortcuts.py` — `ACTION_REGISTRY` 新增 `ActionDef("format_inline_math", "行内公式", "edit", "行内格式", ...)`，默认 `ctrl+m`；`_INLINE_FORMAT_ACTIONS` 元组追加 `"format_inline_math"`（复用 KeyDispatcher `inline_format_combos()` 路由）

### 2. 块级公式（$$...$$）— 可编辑独立岛屿

**核心思路**：浏览态 `ft.Markdown` 渲染 LaTeX，点击进入编辑态显示 `ft.TextField`（多行）编辑源码。参考代码块的 `code_focus_ref` 三件套模式，但用 **state**（`math_focus_li`）驱动重渲染（因为需要条件渲染两种控件）。

**改动：**

- `core/actions.py` — `EditorActions` 新增 `math_focus_ref: ft.Ref` 字段（有默认值区域）
- `views/editor.py`：
  - 新增状态：`math_focus_li`/`set_math_focus_li`（state）、`math_focus_ref`（ref 镜像）、`math_field_ref`、`math_edit_snapshot`、`math_edit_changed`
  - 新增回调：`on_change_math(li, value)`、`on_math_focus(li)`、`on_math_blur(li)`（参考 `on_code_focus`/`on_code_blur`/`on_change_code` 模式）
  - `set_block`（line 886）新增 `BlockType.MATH` 分支：`new_raw = f"$$\n{content}\n$$"`，设置后自动进入编辑态
  - 新增 `use_effect([math_focus_li])` 聚焦公式 TextField
  - `_on_tap_line` 增加：点击非公式行时退出公式编辑态
  - `EditorActions` 构造传入 `math_focus_ref=math_focus_ref`
  - LineView 调用传入 `is_math_editing`/`on_change_math`/`on_math_focus`/`on_math_blur`/`math_field_ref`
- `views/line_view.py`：
  - LineView 签名新增 `is_math_editing`/`on_change_math`/`on_math_focus`/`on_math_blur`/`math_field_ref` 参数
  - MATH 分支替换为调用新函数 `_render_math_block`
  - 新增 `_render_math_block` 函数：
    - 编辑态：`ft.TextField`（多行、等宽、math_fg 色）+ header 提示 + math_bg 背景 + 左侧 math_fg 边框
    - 浏览态：`ft.Markdown`（已有，加 `on_click` 进入编辑态 + `ink=True`）
  - imports 补充 `FONT_MONO`、`only_border`
- `views/key_bindings.py`：
  - `_native_field_focused` 增加 `math_focus_ref` 检查（公式 TextField 聚焦时放行原生编辑键）
  - `_handle_shortcuts` browse/edit 两层新增 `format_math_block`（`ctrl+shift+m`）→ `actions.set_block(BlockType.MATH)`
- `services/shortcuts.py` — `ACTION_REGISTRY` 新增 `ActionDef("format_math_block", "公式块", "both", "格式", ...)`

### 3. 工具栏

- `views/toolbar.py` — 新增 `on_inline_math`/`on_math_block` 参数和按钮（`ft.Icons.FUNCTIONS`）

## 快捷键路由

- **Ctrl+M（行内公式）**：通过 `_INLINE_FORMAT_ACTIONS` → `inline_format_combos()` → KeyDispatcher `handle()` 顶部 `if combo in inline_map:` 分支 → `apply_inline_format("inline_math")` → 插入 `$$`，光标在两 `$` 之间
- **Ctrl+Shift+M（公式块）**：通过 `_handle_shortcuts` 匹配 → `actions.set_block(BlockType.MATH)` → 当前行的内容转为 `$$\n{content}\n$$`，自动进入编辑态

## 块级公式编辑流程

1. **进入**：点击公式块 → `on_math_focus(li)` → `set_math_focus_li(li)` → 重渲染为 TextField → `use_effect` 聚焦
2. **编辑**：TextField `on_change` → `on_change_math(li, value)` → 更新 `line.segments[0].text/raw` + `line.raw` → 首次修改推历史
3. **退出**：TextField `on_blur` / 点击其他行 → `on_math_blur(li)` → `set_math_focus_li(None)` → 重渲染为 ft.Markdown

## 验证

1. **行内公式**：输入 `$E=mc^2$`，浏览态折叠 `$` 只显示 `E=mc^2`（math 样式），光标进入显示 `$` 标记
2. **块级公式**：输入 `$$\n\\int_0^1 x^2 dx\n$$`，浏览态 ft.Markdown 渲染 LaTeX，点击进入编辑态
3. **Ctrl+M**：光标处插入 `$$`，光标在两 `$` 之间
4. **Ctrl+Shift+M**：当前行转为公式块，自动进入编辑态
5. **撤销/重做**：Ctrl+Z 撤销公式编辑/创建
6. **序列化**：保存重新打开，公式正确还原
7. **主题**：亮/暗主题 math_fg/math_bg 配色正确
