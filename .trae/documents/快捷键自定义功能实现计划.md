# 快捷键自定义功能实现计划

## Context

当前快捷键系统存在两类问题：

1. **编辑交互不专业**：设置页"高级"tab 用 `ft.TextField` 让用户手动输入组合键字符串（如 `ctrl+b`）并按回车提交，用户需记忆格式、易输错，且无"按下即捕获"的专业体验。
2. **硬编码导致不可配置**：
   - `views/key_bindings.py` 的 `_INLINE_COMBO_MAP`（L60-67）硬编码 `ctrl+b/i/u/shift+s/`/k` → 行内格式动作，不读 `ShortcutManager` 配置，用户改了 `format_bold` 键位也不生效。
   - `Ctrl+0~6` 标题切换硬编码在 `_handle_shortcuts`（L353-361），未纳入注册表。
3. **现存 bug 阻断"立刻生效"**：`main.py` L611 `ft.use_effect(_bind_keyboard, [])` 空依赖，`_handler` 闭包捕获**首次渲染**的 `dispatcher`。改快捷键后 `settings` state 虽更新，但 `page.on_keyboard_event` 仍调用旧 dispatcher（持有旧 `shortcut_mgr._settings`），新键位不生效，需重启应用。

用户需求："优化整体快捷键功能，保证精准、科学、专业，设置页实现可自定义（点击「修改」，按下新组合键，立刻生效）"。

目标：修复 dispatcher 过期 bug；行内格式快捷键去硬编码；设置页"快捷键"tab 改造为专业编辑入口（修改按钮 → 捕获按键 → 立即生效 → 冲突实时高亮）。

## 架构决策

- **捕获模式复用主 dispatcher**：`page.on_keyboard_event` 在 SettingsDialog（`ft.Stack` 覆盖层，非 modal route）打开时仍触发，无需在设置页内嵌 `ft.KeyboardListener`（避免双键盘源互斥、且 `KeyDownEvent` 无 `ctrl/shift` 布尔位不可靠）。
- **`capturing` state 上提 App 层**：作为 `use_state`，同时传给 `KeyDispatcher`（拦截按键）和 `SettingsDialog`（UI 高亮），符合项目"状态上抛 App 层"约定。
- **`dispatcher_ref` 渲染期同步**：`dispatcher_ref.current = dispatcher` 在组件函数体每次渲染时执行，`_handler` 通过 ref 读最新 dispatcher，顺带修复 dispatcher 过期 bug。
- **"快捷键"tab 成唯一编辑入口**：合并原"高级"tab 的动作列表/冲突卡片/导入导出；"高级"tab 改为占位。
- **Ctrl+0~6 保持固定导航键**：在快捷键 tab 显示说明，标注不可自定义。

## 边界处理

| 场景 | 处理 |
|------|------|
| 纯修饰键（单按 Ctrl/Shift/Alt） | `_combo` 返回 `""`，`if not combo: return` 等待 |
| Escape | 取消捕获 |
| Backspace | 清空绑定（combo=""） |
| 切 tab / 关闭设置页 | `set_capturing((None,None))` 退出捕获 |
| 点另一个 action 的"修改" | `set_capturing` 覆盖，仅新 action 在捕获态 |
| 新组合与已有键冲突 | `update_setting` 触发 `set_shortcut_focus`，重渲染后冲突卡片 + 行红色高亮自动刷新 |
| 代码块/表格原生控件聚焦时按"修改" | 不影响（"修改"是鼠标点击，捕获期键盘由 dispatcher 顶部拦截不传原生控件） |

## 验证

1. **dispatcher 过期修复**：启动应用 → 设置页改 `format_bold` 为 `ctrl+shift+b` → 关闭设置页 → 选中文本按 `Ctrl+Shift+B` → 应触发加粗（旧 bug 下不生效）
2. **行内格式去硬编码**：改 `format_italic` 为 `ctrl+shift+i` → 按 `Ctrl+Shift+I` 触发斜体
3. **捕获交互**：点"修改" → 行变蓝显示"按下新组合键…" → 按 `Ctrl+Shift+S` → 立即显示新键位 + 冲突高亮（若与 `format_strike` 冲突）
4. **Esc 取消**：捕获中按 Esc → 回到正常态，键位不变
5. **Backspace 清空**：捕获中按 Backspace → 显示"未绑定"
6. **冲突实时**：把两个动作绑成同一组合 → 冲突卡片显示 + 两行红色高亮
7. **持久化**：改键位后重启应用 → 新键位保留（settings.json 已保存）
8. **冒烟**：`python main.py` 启动无异常，常规快捷键（Ctrl+S/O/N/Z/Y）仍正常
