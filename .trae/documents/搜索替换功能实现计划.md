# 搜索替换功能实现计划（参考 VSCode / Typora）

## Context（背景）

当前编辑器已有搜索功能（侧边栏搜索面板：搜索框 + 选项工具栏 + 结果列表，支持当前文档/跨文件、大小写/整词/正则、异步扫描防竞态、双色高亮、点击跳转）。但缺少**替换**功能。

用户要求：参考 VSCode/Typora 增加替换，遵循桌面端交互直觉，界面美观科学清晰。

**用户决策**（已确认）：
1. 替换栏 UI：**可折叠（VSCode 式）**——搜索框左侧折叠按钮，Ctrl+H 展开/收起替换栏
2. 替换范围：**当前文档 + 跨文件**（跨文件需写盘）
3. 替换后行为：**替换当前后自动跳到下一个匹配**

## 关键设计决策

### 反向引用展开归 Sidebar，编辑器只做纯文本替换
Sidebar 持有编译后的 `pattern`（`_build_query_regex`），由它对每个匹配 `(li, s, e)` 用 `pattern.finditer` 重建 `re.Match` 并 `match.expand(replace_text)` 得到展开后的 `new_text`。编辑器只接收 `(li, s, e, new_text)` 做字符串替换 + reparse + history。

**好处**：消除 `editor/_replace.py → views/sidebar` 循环依赖；编辑器无需感知 regex；EditorActions 接口更简洁。

### 撤销策略
- 当前文档单次替换 / 全部替换：各用 1 次 `push_history()`（全文快照 `EditorSnapshot`），一次 Ctrl+Z 还原
- 跨文件替换：不入编辑器历史栈（与 VSCode 一致）

### 跨文件替换写盘 + 刷新
`services.file_io.read_text/write_text` + `asyncio.to_thread` 移出 UI 线程 + `replace_token_ref` 防竞态 + `bump_fs_version` 触发跨文件搜索重扫。当前打开文档走内存替换（避免覆盖未保存草稿）。

### 替换后跳转
`pending_jump_idx` state + `use_effect([search_results, pending_jump_idx])`：替换后 `line.raw` 变 → `_lines_sig` 变 → `search_results` use_memo 重算（少一条匹配）→ effect 取新扁平结果 `flat[idx]`（自然成为下一个匹配）→ `on_jump_to_line`。

### 8. `views/sidebar.py` — 核心 UI + 状态 + 回调（改动最大）

**8.1 新增模块级纯函数**（放 `_match_lines` 后，可单测）：
- `_flatten_matches(search_results) -> [(li, s, e), ...]`
- `_flatten_cross_matches(cross_results) -> [(path, li, s, e), ...]`
- `_expand_replacement(match, replace_text, regex_mode) -> str`：regex 用 `match.expand()`，非 regex 转义 `$`/`\` 为字面量
- `_replace_in_string(raw, pattern, spans, replace_text, regex_mode) -> (new_raw, count)`：行内右→左 + 反向引用展开（用 pattern.finditer 重建 Match）
- `_replace_in_file_text(text, pattern, replace_text, regex_mode) -> (new_text, count)`：跨文件单文件按 `\n` 切行替换

**8.2 新增 UI 工厂**：
- `_render_replace_bar(replace_text, set_replace_text, replace_expanded, on_replace_current, on_replace_all, has_query, c)`：折叠时返回 `Container(height=0)`；展开时 Row[替换 TextField(expand=True) + "替换"按钮 + "全部"按钮]，复用 `_option_toggle_text` 样式
- `_render_search_box_with_toggle(...)`：搜索框 + 左侧 `IconButton(ARROW_DROP_DOWN/RIGHT)` 折叠按钮

**8.3 修改 `_render_search_panel`**：新增参数（replace_text/set_replace_text/replace_expanded/set_replace_expanded/on_replace_current/on_replace_all）；header 改为 [搜索框+折叠按钮, 替换条, 工具栏]

**8.4 `Sidebar` 组件**：
- 新增 state：`replace_text/set_replace_text`；`_replace_expanded = settings.get("search_replace_expanded")`；`pending_jump_idx/set_pending_jump_idx`；`replace_token_ref`（跨文件防竞态）
- `_on_set_replace_expanded(v)` → `on_update_setting("search_replace_expanded", v)`
- `_on_replace_current()`：取扁平结果 `flat[idx]` → 当前文档调 `on_replace_match_in_doc(li, s, e, _expand_for_match(...))` → `set_pending_jump_idx(idx)`；跨文件调 `_replace_in_cross_file_single`
- `_on_replace_all()`：当前文档调 `on_replace_all_in_doc(replacements)`（replacements 含已展开 new_text）；跨文件调 `_replace_in_all_cross_files`

- `_replace_in_all_cross_files()`：逐文件 read→replace→write，当前文档走内存；末尾 bump_fs_version
- `use_effect(_do_jump_after_replace, [search_results, pending_jump_idx])`：重算后跳 `flat[idx]`
- 注册回调到 `replace_actions_ref.current = {"replace_current": ..., "replace_all": ...}`（KeyDispatcher 桥接用）
- Sidebar 签名新增参数：`on_replace_match_in_doc`、`on_replace_all_in_doc`、`on_bump_fs_version`、`replace_actions_ref`

## 风险与缓解
- **行内多匹配偏移失效**：行内右→左处理
- **跨文件写盘覆盖未保存草稿**：`path==file_path` 走内存回调
- **跨文件替换竞态**：`replace_token_ref` 自增 + 异步前后校验
- **非 regex 替换文本 `$1` 误展开**：`_expand_replacement` 非 regex 模式转义 `$`→`$$`、`\`→`\\`
- **替换改变块类型**：`reparse_line_atomic` 普通块分支走 `_build_line(raw)` 完整重建，块类型自动更新
- **diff/split 替换作用错视口**：`get_active_nav()` 路由到焦点视口
