### 关键实现
- `views/settings_dialog.py` **整体重写**。右列结构固定为
  `Container(expand=True) > Column(expand=True)[固定头部, 1px 分隔线, Container(expand=True, 唯一滚动区)]`。
  头部（标题 / 说明 / 关闭按钮）在滚动区**之外** → 物理上不可能随内容滚动。
- **真机才发现的真 bug**：拆掉快捷键页内层滚动后，外层 `Column` 漏写 `expand=True`。
  父级 `Row` 的交叉轴约束是「至多 740」而非紧约束 → 外层列按内容取高 → 内层滚动列拿不到有界高度
  → 内容被卡片裁掉**且滚轮完全无效**。修复：外层列与内层滚动列都写 `expand=True`。
  教训：**嵌套滚动拆掉一层时，必须回头检查剩下的容器是否还能给出有界高度**。
- 新增统一行工厂：`_card` / `_badge` / `_switch_row` / `_slider_row` / `_dropdown_row` /
  `_value_row` / `_icon_button` / `_nav_item` / `_header`。标签列 `_LABEL_W=108`、数值列 `_VALUE_W=56` 定宽 → 各行左右边缘对齐。
- 撤掉全部 `ft.IconButton`（Material 固有高 40 压不下去），改用定尺寸 `Container(ink=True)`。
- 侧栏导航项改**整行可点**（`Container(ink=True, on_click=...)` 包 Row），改前只有文字那一点能点。
- 快捷键改动标记：`_shortcut_diff(current, default)` → `""` / `已清空` / `已自定义` / `已修改`；
  **比对前必须 `normalize`**（否则 `ctrl+comma` vs `ctrl+,` 误判为已修改）。角标 + 分类汇总
  「N 项已调整」+ 概览条「已调整 N 项 / 共 M 项」+ 「只看已修改」开关（面板内 `use_state`）。
  清空的项键位框显示**未绑定**，默认键写在说明行，避免「已清空」旁边写 `Ctrl+S` 自相矛盾。
- 新增「关于」页，替换原占位的「高级」tab。行工厂 `_about_row`，回调契约统一为
  `on_open(value)` / `on_copy_value(value)`（邮箱行在内部转 `mailto:`）。
- 新增 `config/app_meta.py`：应用名 / 标语 / 作者 / 许可 / 5 个外链常量 + `app_version()`
  （`importlib.metadata.version`，源码直跑回退 `_FALLBACK_VERSION="0.1.0"`）+ `runtime_summary()` + `mailto()`。
  `views/global_menu.py` 的 6 个硬编码 URL 改为引用它。

### 环境性坑（重要，下次别再误判成回归）
1. 宿主注入了**删除守卫**（`sitecustomize.py` 劫持 `Path.unlink`）：测试里自己 `unlink()` 清沙箱文件
   的用例会直接抛 `SystemExit: 1`（如 `tests/test_first_run_sample.py`）。栈里有 `[safe-delete]` 前缀即环境拦截。
2. 删除计数是**按工具调用累计**的 → 一次调用里连跑多轮回归，越往后越容易整体失败；以**最早那轮摘要**为准。
3. 本机 **PowerShell 工具的输出捕获不稳定**（原生命令输出赋给变量常为空）。
   跑批量回归要用 **Python 编排脚本**（subprocess + 正则取摘要），不要用 PS 循环。
4. OS 级输入注入（`SendInput` / `PostMessage` 滚轮）在本会话**时灵时不灵**：同参数一次滚到底、一次整批丢失。
   真机像素验证结论只取「确实注入成功」的那次运行。
